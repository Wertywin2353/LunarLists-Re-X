## Проект Lunar Lists
Данный проект был создан для личного использования, однако доступен всем. После создания Legacy версии я решил полностью переосмыслить проект с нуля, добавив множество функций и идей, переписав все с начала.

Благодаря удобному UI, удобному функционалу и реализации как WebApp Lunar Lists является доступным\маловесящим инструментом для повседневной жизни. Не смотря на то, что проект направлен в сторону аниме списков, но этот проект можно использовать и в других целях.

## Источники, Зависимости и др.
Иконки предоставлены платформой Icons8.

В проекте используется моя библиотека LazyLib.

Авторы большинства звуков используются SFX Nintendo Switch (из сайта downloads.khinsider.com) или из других платформ с свободным распространением.
